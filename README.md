# TranscribeApp

תוכנת דסקטופ חינמית וקוד-פתוח (Windows + Mac) לתמלול קבצי אודיו/וידאו ארוכים
באמצעות מודל התמלול של OpenAI. מפצלת אוטומטית קבצים גדולים (כדי לעמוד במגבלת
25MB של ה-API), מריצה תור קבצים ברקע, שומרת היסטוריה, ומאפשרת קונפיגורציה
דרך מסך הגדרות (מפתח ה-API נשמר ב-Windows Credential Manager / macOS
Keychain, לא בקובץ טקסט גלוי).

## הורדה

הכי פשוט: עברו לעמוד ה-[**Releases**](../../releases/latest) של הריפו,
והורידו את קובץ ה-zip המתאים למערכת ההפעלה שלכם (Windows / macOS). מחלצים
את ה-zip ומריצים ישירות — אין צורך בהתקנת Python או ffmpeg בנפרד.

**שימו לב:** הקובץ לא חתום דיגיטלית (חתימת קוד עולה כסף), אז ב-Windows
תופיע בהרצה הראשונה אזהרת SmartScreen ("Windows protected your PC"). זה
צפוי — לוחצים **More info** ואז **Run anyway**. ב-Mac ייתכן שתידרש אישור
דומה תחת System Settings → Privacy & Security.

**חשוב:** הכלי לא מגיע עם מפתח API — כל משתמש צריך מפתח משלו מ-
[platform.openai.com](https://platform.openai.com/api-keys) ומזין אותו
פעם אחת במסך "הגדרות" בתוכנה. עלויות השימוש ב-API הן על חשבון כל משתמש
מול OpenAI, לא על חשבון היוצר.

## הרצה מקוד המקור

```bash
pip install -r requirements.txt
python main.py
```

עובד על Windows ו-Mac (ו-Linux, לא נבדק רשמית). דורש Python 3.10 ומעלה.
ffmpeg **לא** צריך להיות מותקן בנפרד — מגיע מוטמע דרך החבילה `imageio-ffmpeg`.

## שימוש

1. **מסך "הגדרות"** — הזינו את מפתח ה-API של OpenAI (או לחצו "ייבוא מקובץ..."
   כדי לייבא אוטומטית מקובץ `keys.env`/`.txt` שבו שמור המפתח, מזהה הארגון
   ומזהה הפרויקט). בחרו מודל תמלול, שפה, ותיקיית פלט (אופציונלי — ברירת
   המחדל היא לשמור ליד קובץ המקור). לחצו "שמור הגדרות".
2. **מסך "תור עבודה"** — גררו קבצי אודיו/וידאו לחלון, או לחצו "הוסף קבצים",
   ואז "התחל תמלול". קבצים גדולים מ-25MB מפוצלים אוטומטית לחלקים ומחוברים
   בחזרה לקובץ טקסט אחד. אפשר לעצור את התור באמצע.
3. **מסך "היסטוריה"** — רשימת כל התמלולים שבוצעו, עם גישה מהירה לקובץ
   ולתיקייה, וסינון לפי שם קובץ.

## בניית תוכנה עצמאית (exe / app)

```bash
pip install -r requirements.txt
python build.py
```

- ב-Windows ייווצר `dist/TranscribeApp/TranscribeApp.exe` — אפשר להעתיק את
  כל התיקייה `dist/TranscribeApp` (או לדחוס אותה ל-zip) לכל מחשב Windows
  אחר ולהריץ, בלי התקנה.
- ב-Mac ייווצר `dist/TranscribeApp.app` — אותו דבר, אפשר להעתיק/לדחוס
  ולהריץ על כל Mac.

**חשוב:** PyInstaller לא בונה חוצה-פלטפורמות — צריך להריץ את `build.py` על
כל מערכת הפעלה בנפרד (למשל, לבנות את גרסת ה-Mac צריך לעשות זאת על מחשב Mac,
או להשתמש בזרימת העבודה האוטומטית שמופיעה למטה).

## בניית שתי הגרסאות בלי מחשב Mac (GitHub Actions)

בתיקייה `.github/workflows/build.yml` מוגדרת זרימת עבודה שבונה אוטומטית
גם גרסת Windows וגם גרסת Mac בענן, ומעלה אותן כקבצי zip להורדה:

1. העלו את התיקייה הזו לריפוזיטורי ב-GitHub (למשל `git init`, `git add -A`,
   `git commit`, יצירת ריפו ב-GitHub, `git push`).
2. ב-GitHub, לשונית **Actions** → **Build TranscribeApp** → **Run workflow**
   (או פשוט צרו tag בשם `v1.0` ו-`git push --tags`).
3. אחרי כמה דקות יופיעו קבצי `TranscribeApp-windows.zip` ו-`TranscribeApp-macos.zip`
   תחת ה-Artifacts של ההרצה — אלה קבצי ה"התקנה" שאפשר להעביר לכל מחשב.

## מבנה הפרויקט

```
TranscribeApp/
  main.py              נקודת הכניסה, טוען את חלון האפליקציה
  app/
    main_window.py      כל מסכי הממשק (תור/היסטוריה/הגדרות)
    worker.py            עיבוד התור ברקע (QThread) כדי שהממשק לא ייתקע
    transcriber.py        פיצול אודיו + קריאות ל-API של OpenAI
    storage.py             הגדרות, היסטוריה, ושמירת מפתח ה-API בקיצ'ריין
  resources/style.qss     עיצוב הממשק
  build.py                 בונה exe/app עם PyInstaller
  .github/workflows/       בנייה אוטומטית של Windows+Mac בענן
```

## אבטחה

מפתח ה-API לעולם לא נכתב לקובץ טקסט על ידי האפליקציה — הוא נשמר דרך
החבילה `keyring` באחסון המאובטח של מערכת ההפעלה. קובץ ה-`keys.env`
המקורי (אם משתמשים ב"ייבוא מקובץ") נשאר איפה שהוא, האפליקציה רק קוראת
ממנו פעם אחת בזמן הייבוא.
